# Smoke test

## Быстрый прогон MVP

1. **Регистрация**: открой `/login` → таб «Регистрация» → email + пароль (≥6 симв).
2. **Промокод**: на `/play` → кнопка «Промокод» → введи `DEMO2025` → доступ ко всем 10 сценариям.
3. **Старт**: выбери любой сценарий → «Начать» → попадёшь на `/play/run/<id>` с приветствием.
4. **Игра**: пиши действия (≤80 симв.), Enter. ИИ отвечает за 2–6 сек.
5. **Чекпойнт**: на 7-м шаге увидишь плашку «⭐ Чекпойнт сохранён».
6. **Резюм**: перезагрузи страницу — история подтянется из БД.
7. **Финал**: либо ИИ выставит финал, либо принудительно на 50-м шаге → появится финальная картинка.

## Что проверить в БД (Lovable Cloud → Database)

- `runs.status` меняется `active → finished`, `step_count` растёт.
- `messages` пишутся для каждого хода (role: user/assistant).
- `runs.summary` обновляется после чекпойнтов.
- `entitlements` создалась запись после промокода, `promo_codes.used_count` инкрементнулся.

## Лимиты (защиты)

- ≤80 символов ввода (UI + сервер режут).
- Не чаще 1 шага в 1.2 сек на run → 429.
- Не больше 30 шагов/мин на пользователя → 429.

## Известные ограничения MVP

- Стриминг ответа имитируется индикатором «печатает» (фактически non-stream — для надёжного парсинга META).
- Финальные картинки — placeholders на placehold.co. Замени `scenarios.final_image_url` на свои.
- Оплата не подключена — только промокоды (`DEMO2025` создан в seed).
- Админка не реализована (есть только `role='admin'` поле в `profiles`).
